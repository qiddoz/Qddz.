Design choices

I used a dark theme with teal and amber accents so the site feels modern and the text stays easy to read. The name Qddz appears in the logo and headings to build a personal brand. I used one external stylesheet so every page looks consistent, cards and timelines to break up long text, and a sticky menu so navigation is always close.

Challenges

  • Keeping the layout good on both phones and computers.
  • Making the image map still work when the picture is resized.
  • Learning JavaScript for the clock, the notification and the search.
  • Publishing the site correctly on GitHub Pages.

Lessons learned

  1. Plan the structure first, then write the code.
  2. Comments and clear file names save time later.
  3. Accessibility (alt text, contrast, text size) helps every visitor.
  4. Test every link before submitting.
