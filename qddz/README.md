# Qddz - Personal Website of Aqid (IMD318 Individual Project, UiTM)

Hand-written HTML, CSS and JavaScript. No templates or frameworks.

## Structure
- `index.html` Home (clock, typing text, image map, search, external links)
- `biodata.html`, `experience.html`, `education.html`, `skills.html`, `family.html`
- `gallery.html` (images, video, audio), `contact.html`, `sitemap.html`, `reflection.html`
- `css/style.css`, `js/script.js`, `images/`, `media/`

## Before you submit
Search every file for `[edit:` and replace each highlighted placeholder with your real details.
Replace `images/avatar.png` and the gallery pictures with your own photos (same file names, or update the HTML).

## Publish on GitHub Pages
1. Create a new GitHub repository (e.g. `qddz`), public.
2. Upload ALL files and folders (keep `index.html` at the top level), or:
   `git init && git add . && git commit -m "Qddz site" && git branch -M master && git remote add origin <repo-url> && git push -u origin master`
3. Repository > Settings > Pages > Source: Deploy from a branch > Branch: `master` / root > Save.
4. Your site appears at `https://<username>.github.io/<repo>/` after a minute or two.
